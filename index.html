    Projects

    Reelsmith v2 Live in production

    AI agent that tracks trends, writes and voices short videos, edits them and publishes on a schedule — running on free tiers with Render, Supabase and GitHub Actions as the render farm.

    Problem
    Running a Shorts / Reels channel means finding a topic, writing, recording and editing — every single day.
    What it does
    An AI pipeline does that work and posts to YouTube Shorts and Instagram Reels on a schedule.
    How it works
    Trend scan → script (8 AI providers with automatic fallback) → voice-over → video rendered on GitHub Actions → approve in the dashboard → publish.
    Safety
    Tragedies, elections and NSFW topics are filtered out, and nothing is posted without approval until autopilot is switched on.
    • GitHub Actions

    Muse Studio Live in production

    Dashboard for running five fictional AI virtual creators on Instagram, with safety built in: AI disclosure, SFW publish gate, per-account posting caps, duplicate checks and a kill switch. Backed by a FastAPI service with JWT auth and a 64-test suite.

    Problem
    AI “influencer” accounts are easy to misuse — fake people, hidden AI, spam.
    What it does
    One dashboard runs five clearly fictional AI creators on Instagram — the responsible way.
    How it works
    Generate the character's look → lock it as a reference → draft posts → every post must pass a Publish Gate before it goes out.
    Rules built in
    AI disclosure on every post, SFW check, posting limits, duplicate checks and a kill switch — covered by 64 automated tests.
    • FastAPI
    • Python
    • JWT
    • Docker
    • Vercel

    Project Management API Under construction

    REST API for a project-management system: users and roles, projects with members, tasks with assignment, filtering, search, pagination, soft delete and activity history, comments, avatar uploads and per-project dashboards.

    Problem
    Teams need a backend to track projects, tasks and who is doing what.
    What it does
    The engine behind a Trello / Jira-style app — 36 REST endpoints.
    How it works
    Users sign in and get a JWT token; their role (admin, owner, member) decides what they can see and change. Tasks support search, filters, pages, comments and history.
    Security
    Hashed passwords (bcrypt), login rate limiting, input validation and security headers.
    • Node.js

    • MongoDB

    AnizOoal Animation Studio Under construction

    Web-based animated episode studio with a Node.js API, Supabase persistence with row-level security, and a Render blueprint deploying a web service plus a background publishing worker. Secrets kept strictly server-side.

    What it is
    A browser studio that makes short animated episodes (vertical, 30–60 s) for Shorts and Reels.
    How it works
    AI writes the hooks and a scene plan → layered SVG characters animate in the browser → FFmpeg turns it into an MP4 → saved to Supabase.
    Publishing
    A background worker posts through the official YouTube and Instagram APIs, with review mode, admin-only controls and an emergency stop.
    Security
    Database row-level security; API keys stay on the server, never in the browser.

    Python cybersecurity toolkit with 28 tools: port scanner, packet sniffer, SSH brute-force detection, SQLi/XSS/SSL/header checks, subdomain and directory scanning, file integrity, log analysis, crypto (AES/RSA/hashing) and ML-based phishing, malware and anomaly detection.

    Use
    Made for my own lab and systems I'm authorised to test.

    May~be — Music Aggregator Under construction

    Cross-platform app that unifies Spotify, YouTube Music and Apple Music through OAuth 2.0 PKCE, with lossless audio, gapless playback, offline downloads and a theme that adapts to the album art. Privacy-first: tokens stay in the OS keychain.

    Problem
    Your music is split across Spotify, YouTube Music and Apple Music.
    What it does
    One Flutter app that shows all your libraries together and plays them.
    How it works
    You sign in to each service with OAuth 2.0 (PKCE); a separate adapter talks to each platform. Login tokens are kept in the phone's secure keychain.
    Design goals
    Privacy-first — no ads, no tracking — plus offline downloads, gapless playback and colours that follow the album art.
    • Flutter
    • Dart
    • OAuth 2.0
    • Node.js
    • Prisma
    • Docker

    Deepfake detection for images, video and audio using ensemble models, multi-scale fusion and temporal analysis — a security-meets-ML project.

    Problem

    What it does

    How it works
    Several AI models (EfficientNet, ViT, Xception and more) vote together; videos are checked frame by frame over time; audio is checked through its spectrogram.
    Use it from
